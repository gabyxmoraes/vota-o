# Perfil Biográfico: Luiz Inácio Lula da Silva

Repositório de página estática desenvolvida em HTML5 e CSS3 contendo dados históricos, eleitorais e institucionais sobre Luiz Inácio Lula da Silva.

## Estrutura do Projeto
- `index.html`: Estrutura semântica com linha do tempo e perspectivas políticas.
- `style.css`: Estilização responsiva para visualização em navegadores e GitHub Pages.

## Fontes de Referência
- Tribunal Superior Eleitoral (TSE) — Dados de candidaturas e resultados eleitorais.
- Presidência da República (Biblioteca da Presidência) — Registros oficiais de mandatos.
- Supremo Tribunal Federal (STF) — Decisões judiciais referentes aos processos da Operação Lava Jato.
